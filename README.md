## 🌐 NEXUS MC

**NEXUS MC** is a Minecraft network project designed around a scalable multi-server architecture.

### Architecture

```text
                    ┌─────────────┐
                    │   Players   │
                    └──────┬──────┘
                           │
                           ▼
                    ┌─────────────┐
                    │   Velocity  │
                    │    Proxy    │
                    └──────┬──────┘

              ┌────────────┼────────────┐
              ▼            ▼            ▼
         ┌─────────┐  ┌─────────┐  ┌─────────┐

         └─────────┘  └─────────┘  └─────────┘
```

Focused on:
